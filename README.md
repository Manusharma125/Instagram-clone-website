## ✨ About The Project

**Instagram Clone** is a modern and responsive social-media UI built using **React.js** and **Vite**.

The main goal of this project was to recreate the look and feel of Instagram while practicing real-world React concepts such as **component-based architecture, props, state management, reusable components, responsive layouts, and modern UI development**.

> 🎯 This project is built for learning and portfolio purposes and is **not affiliated with Instagram or Meta**.
